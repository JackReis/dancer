# Templates

## Standard Creativity
```
Generate 5 diverse options (p<0.10 each) for [TASK].
Enable extended thinking.
Select the best one.
Output with brief reasoning for why it won.
```

## Maximum Creativity
```
Generate 5 maximally divergent options for [TASK].
Avoid cliches, obvious approaches.
Enable extended thinking.
Output the most surprising viable option.
```

## Tree of Thoughts
```
Decompose [PROBLEM] into [N] sub-problems.
For each, generate 3-5 approaches.
Evaluate combinations.
Prune weak branches.
Output best path + rationale per sub-decision.
```
