# Principles

1. **Internal diversity first** — Generate multiple options internally before committing
2. **Extended thinking is mandatory** — VS only works with deep deliberation
3. **Quality over quantity** — One excellent output beats five good ones
4. **Domain awareness** — Tailor approach to the specific domain
5. **Not for single-answer tasks** — VS provides no lift where there's one correct answer
6. **Evolutionary vs. single-pass** — For deep ideation, use ideate instead
