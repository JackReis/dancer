# Standard Creativity Workflow

Standard deep thinking + Verbalized Sampling for quality creative work.

## Execution

1. Read the request carefully
2. Enable extended thinking
3. Internally generate 5 diverse options (p<0.10 each)
4. Evaluate each internally
5. Output the single best response with reasoning

## When to use

Most creative requests — creative angles, naming, framing, unconventional approaches.
