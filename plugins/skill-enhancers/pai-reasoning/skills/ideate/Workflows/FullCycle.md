# Full Cycle Workflow

All 9 phases, adaptive. The default ideate workflow for multi-cycle evolutionary ideation.

## Execution

### Phase 1: CONSUME
Use Research skill to gather multi-domain raw material. Extract atomic ideas from each source.

### Phase 2: DREAM (noise=0.9)
Free-association on random input subsets. No problem awareness. High diversity output.

### Phase 3: DAYDREAM (noise=0.5)
Tangential wandering with the problem held loosely. Medium noise.

### Phase 4: CONTEMPLATE (noise=0.1)
Mandatory checkpoint A. Structured analysis via 4 lenses (Literal, Failure, Analogical, Constraint Inversion).
Invokes iterative-depth for lens rotation.

### Phase 5: STEAL
Cross-domain pattern borrowing via weighted random domain lottery.

### Phase 6: MATE
Genetic recombination via Fisher-Yates shuffle + 8 mutation operations.

### Phase 7: TEST (checkpoint B)
Multi-judge scoring on Feasibility/Novelty/Impact/Elegance. Optional external validation hooks.

### Phase 8: EVOLVE
Selection: kill bottom 50%, elite top 10%, mutate the rest, immigrant injection.

### Phase 9: META-LEARN
Lamarckian strategy adjustment + next-cycle question generation.

### Post-Loop: The Historian
Runs Insight Extractor for cross-cycle pattern analysis.

## Loop Controller

Owns inter-cycle state and makes continue/pivot/stop decisions after each cycle's META-LEARN phase.
