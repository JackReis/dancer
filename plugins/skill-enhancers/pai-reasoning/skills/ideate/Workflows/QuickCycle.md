# Quick Cycle Workflow

Compressed CONSUME + STEAL + MATE + TEST single cycle. Fast ideation with scoring.

## Execution

1. CONSUME: Quick research on the problem domain (3-5 sources)
2. STEAL: Cross-domain pattern borrowing (2-3 foreign domains)
3. MATE: Recombine extracted ideas (Fisher-Yates shuffle + mutations)
4. TEST: Score candidates on Feasibility/Novelty/Impact/Elegance

## Output

Ranked list of 5-10 candidates with scores and brief descriptions.
