# Science Templates

## Goal Template

```
GOAL: [One sentence — what does "done" look like?]
SUCCESS CRITERIA:
- [Measurable criterion 1]
- [Measurable criterion 2]
CONSTRAINTS:
- [Hard limit 1]
- [Hard limit 2]
ACCEPTANCE: [Who decides? How?]
```

## Hypothesis Template

```
H[1-3]: [Specific, testable statement]
FALSIFIED IF: [Observable condition that disproves it]
```

## Experiment Template

```
HYPOTHESIS: [Which hypothesis this tests]
TEST: [Concrete action — what changes?]
MEASUREMENT: [Data source + method — how do we know?]
FALSIFICATION: [What result disproves the hypothesis?]
CONFOUNDERS: [Alternative explanations to rule out]
```

## Results Template

```
EXPERIMENT: [What was tested]
RAW DATA: [Numbers, not interpretation]
ANOMALIES: [Unexpected observations]
VERDICT: [CONFIRMED / REFUTED / INCONCLUSIVE]
CONFIDENCE: [High/Medium/Low — with reasoning]
```
