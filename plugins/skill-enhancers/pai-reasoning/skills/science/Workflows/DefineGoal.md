# Define Goal Workflow

**Phase 0 of the Scientific Cycle**

You cannot judge experiments without success criteria. This workflow ensures crystal-clear goals before any investigation begins.

## Steps

1. State the goal in one sentence. What will be true when you're done?
2. Define success criteria — specific, measurable, time-bound.
3. Identify constraints — what you CANNOT change.
4. Determine acceptance — who decides if it's done, and how?

## Output Format

```
GOAL: [One sentence]
SUCCESS: [Measurable criteria]
CONSTRAINTS: [Hard limits]
ACCEPTANCE: [Who decides, how]
```
