# Design Experiment Workflow

**Phase 3 of the Scientific Cycle**

Design the smallest experiment that meaningfully tests the hypothesis.

## Steps

1. What is the minimum observation that would falsify this hypothesis?
2. How will you measure it? Define the exact data source.
3. What are the confounders? List at least 2 alternative explanations.
4. Define the test boundary — what exactly changes, and what stays the same?

## Output Format

```
Hypothesis: [H1 statement]
Test: [Concrete action]
Measurement: [Data source + method]
Falsification condition: [What result would disprove H1]
Confounders: [List 2+ alternative explanations]
```
