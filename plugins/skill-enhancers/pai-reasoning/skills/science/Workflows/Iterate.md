# Iterate Workflow

**Phase 7 of the Scientific Cycle**

The feedback loop. Based on analysis, decide what's next and close the cycle.

## Options

1. Apply — the solution works, ship it.
2. Adjust — small change to the hypothesis, new test.
3. Pivot — fundamentally different approach.
4. Expand scope — the problem is bigger than expected.
5. Close — the hypothesis is refuted, try another.

## Decision Matrix

| Confidence | Effect size | Recommendation |
|-----------|-------------|----------------|
| High | Large | Apply |
| High | Small | Adjust + iterate |
| Medium | Large | Apply with monitoring |
| Medium | Small | Pivot |
| Low | Any | Expand scope or pivot |
