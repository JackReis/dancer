# Analyze Results Workflow

**Phase 6 of the Scientific Cycle**

Compare results to the goal. Ensures honest, objective analysis without confirmation bias.

## Steps

1. Return to the goal — what did success look like?
2. Map results — what does the data actually say about each criterion?
3. Surface assumptions — what did you take for granted that the data challenges?
4. Identify the gap — between desired and actual, what's the delta?

## Output

```
Goal: [restated]
Result vs goal: [comparison per criterion]
Assumptions challenged: [list]
Gap: [what remains to be closed]
```
