# Measure Results Workflow

**Phase 5 of the Scientific Cycle**

Collect data from experiments. Ensures measurement is accurate, complete, and unbiased.

## Steps

1. Run the experiment exactly as designed.
2. Record raw data — numbers, not interpretations.
3. Note any anomalies — things that didn't go as expected.
4. Compare to the falsification condition — does this confirm or refute?

## Report

```
Experiment: [what you did]
Raw result: [the data, unfiltered]
Anomalies: [unexpected observations]
Verdict: [CONFIRMED / REFUTED / INCONCLUSIVE]
Confidence: [high/medium/low with reasoning]
```
