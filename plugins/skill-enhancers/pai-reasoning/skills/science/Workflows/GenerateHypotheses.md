# Generate Hypotheses Workflow

**Phase 2 of the Scientific Cycle**

Never test just one idea. This workflow ensures you generate multiple competing hypotheses before experimentation.

## Steps

1. Generate minimum 3 hypotheses — each as a complete, testable statement.
2. For each: What would prove it wrong? (falsification question)
3. Ensure independence — hypotheses should be genuinely different, not variations on the same theme.
4. Rank by testability — which can be falsified fastest?

## Output Format

```
H1: [Statement] — falsified if [condition]
H2: [Statement] — falsified if [condition]
H3: [Statement] — falsified if [condition]
```
