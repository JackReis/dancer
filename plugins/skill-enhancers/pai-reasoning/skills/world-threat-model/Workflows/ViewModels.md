# View Models Workflow

## Purpose

Read and summarize current world model state.

## Execution

### Step 1: Check INDEX.md

See last-updated dates for all horizon models.

### Step 2: Summarize Each Horizon

For each of the 11 horizons (6-month to 50-year):
- Key geopolitical trends
- Technology trajectory
- Economic outlook
- Social/cultural shifts
- Security risks
- Wildcard possibilities

### Step 3: Check Scenarios

Review scenario models in `Scenarios/` subdirectory.

### Step 4: Status Report

Output a summary of model freshness and key observations across horizons.
