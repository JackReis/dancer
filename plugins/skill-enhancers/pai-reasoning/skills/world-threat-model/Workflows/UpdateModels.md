# Update Models Workflow

## Purpose

Refresh world model content with new research or analysis.

## Execution

### Step 1: Review Current Models

Read each horizon model and note:
- What's changed in the real world since last update
- What assumptions have been invalidated
- What new data is available

### Step 2: Gather New Research

Use the Research skill to gather:
- Geopolitical developments
- Technology breakthroughs or failures
- Economic shifts
- Social/cultural changes
- Environmental data

### Step 3: Update Each Model

For each horizon, update:
- Geopolitical landscape
- Technology trajectory
- Economic conditions
- Social/cultural factors
- Security considerations
- Wildcard events

### Step 4: Validate

Run TestIdea on a known historical decision to verify the updated models produce reasonable predictions.
